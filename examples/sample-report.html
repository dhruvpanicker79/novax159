Executive summary

USP-01The same defect, judged by what the port is for

Server-to-server SMTP is opportunistic by design (RFC 7435), so a certificate failure there is expected. On a port carrying credentials, RFC 8314 makes the identical defect critical. Generic TLS scanners apply one rule to both and drown analysts in false alarms.
